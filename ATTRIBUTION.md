# Attribution and provenance

This is WHYtian's research snapshot on uncertainty in stock return forecasting and cross-sectional ranking, not the official StockMixer repository.

- StockMixer architecture and baseline: [SJTU-DMTai/StockMixer](https://github.com/SJTU-DMTai/StockMixer), AAAI 2024.
- Local upstream checkout HEAD at export: `cce13598afd3ff33ae317700a85ae08db0554652`. Research files and local modifications are not claimed to be part of that upstream commit.
- Beta-NLL methodological reference: [martius-lab/beta-nll](https://github.com/martius-lab/beta-nll), Seitzer et al., ICLR 2022.
- Additional papers, links, and evidence-level notes are preserved in [plan/notes.md](plan/notes.md).

The upstream checkout did not contain a top-level license file at the recorded commit. This snapshot does not assign a new blanket license to upstream-derived material or grant rights to excluded third-party datasets.

Exported on 2026-09-30. Original experiment manifests preserve input SHA256 hashes and historical machine paths for traceability; those paths are not portable commands. Data, checkpoints, per-stock prediction arrays, credentials, caches, and unrelated local files are excluded.

No new training result was produced as part of this publication. Earlier reports are historical records; the latest A1 report explicitly distinguishes the unsuccessful primary hypothesis test from exploratory secondary observations.
